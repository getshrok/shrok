<objective>
Build the three self-contained foundation modules of the app-serving subsystem, ported from the
verified PoC into shrok's `src/` and conventions. None of these import the VMS package (they use Node
globals + node:sqlite + runtime dynamic import), so this plan runs in parallel with the dependency add
(Plan 01).

- `src/apps/discovery.ts` — filesystem discovery, the `SLUG_RE` traversal guard, the `AppMod`/`Loaded`
  types, `listApps()` (enumeration, no import) and `loadApp()` (per-request load with the per-app
  load-time error boundary) (D-01/D-02/D-04/D-09).
- `src/apps/adapter.ts` — the ~15-line Express↔web-Fetch bridge with the D-07 parsed-body fix (D-06/D-07).

Purpose: these are the load-bearing, de-risked core. Plan 03 (router) composes them.
Output: three new modules under `src/apps/` that typecheck and are unit-tested.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem slug/name → path.join | A `:slug` directory name or a db `name` could contain traversal sequences; must be validated before any path join. |
| agent-authored app.ts → host process | A discovered module may throw at import or be malformed; must be caught at the discovery boundary so it cannot crash the host. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-02-TRAVERSAL | Information Disclosure | discovery.loadApp / db helper name | mitigate | SLUG_RE `/^[a-z0-9][a-z0-9-]*$/` + reserved `_`-prefix guard before any path.join in loadApp; `/^[a-z0-9_-]+$/i` name guard in the db helper (PATTERNS T-49-01-TRAVERSAL precedent). A `../` or `_pkg` slug yields undefined, never a read outside the apps dir. |
| T-55-02-CRASH | Denial of Service | discovery.loadApp | mitigate | Per-app load-time error boundary (try/catch around dynamic import + export validation) registers a broken app as `{ error }` and never throws — one bad app cannot crash discovery or the host (D-09 → APPSRV-04). |
| T-55-02-ISO | Information Disclosure | per-app db helper | mitigate | Each app's sqlite is co-located in apps/<slug>/ and the helper opens only paths under the passed app dir; an app cannot name a path into another app's folder (name guard rejects `/`, `.`). |
| T-55-02-EXEC | Elevation | dynamic import of app.ts | accept | Apps run in-process by design (REQUIREMENTS.md "same trust posture as skills/sensors/tasks; no new sandbox"). The authoring agent already has file/bash tools. |
</threat_model>
