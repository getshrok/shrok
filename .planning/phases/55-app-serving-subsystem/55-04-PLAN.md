<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| same-origin browser → /apps POST | CSRF protection is carved out for /apps/*; the compensating control is session auth + non-public binding + same-origin browser. |
| /apps mount ↔ SPA catch-all | Mount ordering determines whether /apps/* is served or swallowed by the SPA fallback. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-04-CSRF | Spoofing | /apps/* CSRF carve-out | mitigate | The carve-out removes CSRF for /apps/* (required — the VMS adapter sends no token). Compensating controls: mount is AFTER sessionMiddleware so requireAuth gates app-data routes (Plan 03); the dashboard binds 127.0.0.1 by default and is not publicly exposed; the carve-out is scoped to the `/apps/` prefix only, leaving the rest of the dashboard's CSRF guard intact. Test asserts a tokenless same-origin POST is accepted but the route still requires auth. |
| T-55-04-SHADOW | Tampering | mount ordering | mitigate | /apps is mounted before the SPA `GET '*'` catch-all (D-05) so app routes aren't swallowed; verified by line-order assertion + integration test. |
| T-55-04-ISO | Information Disclosure | per-app sqlite | mitigate | Integration test directly reads each fixture's co-located sqlite and asserts one app's writes never appear in another's DB (D-03 co-location → APPSRV-05). |
| T-55-04-CRASH | Denial of Service | broken app | mitigate | Integration test asserts a throwing app's 500 is local while siblings + the host stay up (D-09 → APPSRV-04). |
</threat_model>
