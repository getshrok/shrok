<objective>
Persist every *inbound* message a sub-agent receives to the `agent_messages` table at the
moment it enters the conversation, mirroring how the head persists both sides of its turn to
the `messages` table. Today sub-agents persist only LLM-*generated* output (assistant turns,
tool calls/results) via the `runToolLoop` `appendMessage` callback; the inbound half (initial
task, `message_agent` updates, resume answers, sub-agent notices, synthetic skill reads) lives
only in the in-memory `history` array and never reaches the DB.

Purpose: (1) the dashboard agent-stream view renders the full inbound+outbound conversation
for free (`MessageBubble` already handles `role:user` and `injected` rows); (2) fixes a latent
resume-divergence correctness bug where the DB resume path (`resumeSuspended`) sees a different
history than the in-memory path.

Output: `src/sub-agents/local.ts` writes inbound rows at each inject point; tests prove
persistence, single-store idempotency for `message_agent`, and no duplicated first turn after
resume; a CHANGELOG entry.

**Hard scope boundary (additive only):** The in-memory `history` array STAYS as the working
buffer. Do NOT remove it, do NOT make the loop DB-sourced, do NOT touch `work_start`, do NOT
collapse the two `update()` resume paths. Those are Phase 54.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-53-01 | Information Disclosure | persisting inbound task / message_agent / skill-read content to agent_messages | accept | No NEW data class is exposed: the task already lives in the `agents.task` column, message_agent payloads already transit the inbox table, and skill instructions are already on disk in the workspace. The `agent_messages.data` column is local-only and already trusted (it already stores assistant output, tool calls, and tool results including any secrets the agent surfaced). This phase writes a subset of already-in-process, already-persisted-elsewhere conversation content to the same trust zone. No secrets newly cross a boundary. |

| T-53-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this phase — uses only existing in-repo primitives (`appendMessages`, `emitMessageAdded`). Package legitimacy gate not applicable. |

No `high`+ findings. Surface is internal, local-only, and additive.
