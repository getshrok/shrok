return new Promise(resolve => {

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-48-01 | Tampering | `runSensor` path construction from `slug` | mitigate | Slug guard `/^[a-z0-9][a-z0-9-]*$/` throws BEFORE any `path.join`, rejecting `.`, `/`, `..` (Task 2). |
| T-48-02 | Denial of Service | sensor stdout size | mitigate | `stdout.slice(0, SENSOR_OUTPUT_CAP)` truncates before write; Node's default `execFile` maxBuffer (1 MB) is a second backstop (Task 2). |

| T-48-04 | Elevation of Privilege | sensor script runs arbitrary operator code with server env | accept | By-design operator trust (D-11); no sandbox this milestone.
