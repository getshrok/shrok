## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ambient/*.md file content → system prompt | Sensor output is concatenated into the system prompt as plain `## <Label>` context text. It is operator-authored situational data, not user input, and is never interpreted as an executable instruction beyond ordinary context. |
| cache-split marker | The `\n\nCurrent time:` marker is the line everything-after of which is uncached; misplacing the ambient block above it leaks frequent updates into the cached prefix (a cost/cache bug, not a security breach). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-08 | Information Disclosure | ambient block placed above the cache marker busting prompt cache | mitigate | All three injections append AFTER the `Current time:` line; the assembler test pins `indexOf('## Weather') > indexOf('Current time:')` (Task 1). |
| T-48-09 | Tampering | sensor file body treated as model instruction | accept | Ambient content is rendered as plain `## <Label>` context text — the same trust as identity/skill files the model already reads. No new privilege; operator-authored. Scan emits only headings + bodies, never tool-call directives. |
| T-48-10 | Denial of Service | a huge ambient/*.md body bloating every turn | mitigate | The runner's `SENSOR_OUTPUT_CAP` (Plan 01) bounds each file at write time; the scan concatenates already-capped files. |
