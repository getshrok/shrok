<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator browser → /api/sensors | authenticated operator supplies slug (URL param) + script body (JSON) that become a filesystem path and an executable file |
| operator browser → /api/schedules | authenticated operator supplies kind/taskName/headId persisted as a schedule row |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-01-TRAVERSAL | Tampering | sensors.ts `:slug` handlers | mitigate | Validate `slug` against `/^[a-z0-9][a-z0-9-]*$/` and reject with 400 BEFORE any `path.join` on every get/put/delete (Task 2). Blocks `../`, absolute, and out-of-charset slugs from writing/deleting outside `sensors/` and `ambient/`. |
| T-49-01-AUTHZ | Information Disclosure / Elevation | all /api/sensors routes | mitigate | Every handler registered with the existing `requireAuth` middleware (Task 2); same gate as all other dashboard routes — only authenticated operators reach read/write/delete. Test asserts a route returns 401 without auth. |
| T-49-01-CODEEXEC | Elevation of Privilege | sensor script body executed by SensorRunner | accept | Saving an executable sensor body is operator-privileged by design (the operator already owns the box; same trust as task write-along scripts — REQUIREMENTS.md "Out of Scope"). Only authenticated operators reach the write path (T-49-01-AUTHZ); no untrusted principal can save a script. |
| T-49-01-DELETE-ENOENT | Tampering | DELETE ambient cleanup | mitigate | `fs.rmSync(ambientPath, { force: true })` swallows ENOENT so a never-ran sensor (no ambient file) deletes cleanly without throwing or leaving partial state (Task 2). |
| T-49-01-SC | Tampering | npm/pip/cargo installs | accept | No new packages introduced this phase (RESEARCH.md "no installs"); legitimacy gate N/A. |
</threat_model>
