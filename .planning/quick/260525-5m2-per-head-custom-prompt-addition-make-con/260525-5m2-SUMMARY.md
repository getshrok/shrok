## What Was Built

### Task 1 — Schema + Assembler + Wiring

- `HeadConfigSchema` gains `customPrompt: z.string().optional()`
- `ResolvedHead` interface gains `customPrompt?: string`
- `resolveHeads()` passes customPrompt through with a conditional spread (satisfies `exactOptionalPropertyTypes`); synthesized default head omits the key
- `ContextAssemblerImpl` gets two new defaulted constructor params at positions 10 and 11: `headId: string = 'default'` and `customPrompt?: string`
- Assembler injects `## Head-Specific Instructions\n{customPrompt.trim()}` between the environment block and `Current time:` only when customPrompt is non-empty and non-whitespace
- **Bug fix:** `getRecent('default', ...)` and `getRecentTextByTokens('default', ...)` → `getRecent(this.headId, ...)` / `getRecentTextByTokens(this.headId, ...)`
- `buildSystem` SystemDeps gains `customPrompt?: string`; threads `deps.headId ?? 'default'` and `deps.customPrompt` into ContextAssemblerImpl
- `src/index.ts` per-head loop passes `...(head.customPrompt !== undefined ? { customPrompt: head.customPrompt } : {})` into buildSystem deps
- `tests/unit/assembler.test.ts` line ~31: `ConstructorParameters<typeof ContextAssemblerImpl>` narrowed to explicit 6-tuple `[IdentityLoader, MessageStore, AgentStore, SkillLoader, Config, McpRegistry]`

### Task 2 — Dashboard API

- `PATCH /:id` refactored: `hasRename = typeof body.newId === 'string'` and `hasCustomPrompt = typeof body.customPrompt === 'string'`; returns 400 only when both are absent
- Reserved-id guard (RESERVED_HEAD_IDS) moved inside the `hasRename` branch — `customPrompt`-only PATCH on `'default'` head is allowed
- Empty string `customPrompt: ''` persists as an explicit clear (200, not 400)
- GET `/api/heads` includes customPrompt via conditional spread from `ResolvedHead.customPrompt`

### Task 3 — Dashboard UI

- `HeadDTO` gains `customPrompt?: string`
- `api.heads.setCustomPrompt(id, customPrompt)` added (PATCH with `{customPrompt}`)
- `HeadCard`: `promptDraft` state initialized from `head.customPrompt ?? ''`; `customPromptMutation`; textarea + Save button + loading state + error display placed below the channel rows section
