<objective>
Issue #12: give each head an optional custom system-prompt addition, editable from the dashboard, appended to that head's system prompt. Today all heads share ONE global identity (identityLoader.loadSystemPrompt()) and HeadConfig is only `{ id, channels }`. This plan adds a per-head `customPrompt`, makes ContextAssemblerImpl head-aware (fixing the latent multi-head history bug where non-default heads read the default head's history), and exposes the field through the dashboard.

Purpose: per-head identity divergence without forking the global identity; and a correctness fix so each head's assembler reads its own conversation history.
Output: schema + assembler + wiring changes, a dashboard editor, and tests covering config pass-through, prompt injection ordering, the head-aware history bug fix, and independent PATCH update.
</objective>
