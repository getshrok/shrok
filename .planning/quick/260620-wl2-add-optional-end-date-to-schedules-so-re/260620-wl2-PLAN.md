<objective>
Add an OPTIONAL `endDate` to schedules. Once a recurring schedule's next computed fire would land on/after `endDate`, the scheduler auto-disables it (enabled:false, nextRun:null) rather than arming the next run. The feature mirrors the existing `runAt` field end-to-end; every touch point follows the runAt/startAt pattern already in the codebase.

Purpose: let a recurring schedule stop firing after a user-chosen cutoff instead of running forever.
Output: model + scheduler + agent tools + dashboard API/UI changes, two new tests, and a CHANGELOG entry.
</objective>
