## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN client → GET /media/ring.mp3 | Unauthenticated route reachable by anyone on the network |
| inbound HA Host header → adapter.cacheBaseUrl | Attacker-influenceable header value; only used to build a URL handed to the user's own HA |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-03-TRAV | Information Disclosure | /media/ring.mp3 route | mitigate | V4: literal-match route, NO `:filename`/path param, NO traversal possible — serves only the fixed bundled assets/ring.mp3. Exposure limited to "anyone on the LAN can fetch a beep" (harmless static asset). No session middleware/auth bypass surface |
| T-45-03-HOST | Tampering | Host-header → cached base URL | mitigate | Capture runs ONLY after Bearer auth passes (authenticated inbound HA turns); loopback hosts skipped; the value is never used for an auth decision — only to build the media_content_id URL handed to the user's own HA. publicBaseUrl override available when the captured value is wrong |
| T-45-03-MOUNT | DoS (route shadowing) | mount order | mitigate | Route mounted before express.static + app.get('*') (Pitfall 8) so the SPA fallback cannot shadow it; verified by line-order acceptance check |
