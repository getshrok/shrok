| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-04-ENUM | Input Validation (V5) | ring_device action | mitigate | `action` is a schema enum constrained to ['start','stop']; runtime treats any other value as a safe no-op/ok — never an arbitrary HA service call. Asserted by grep + test |
| T-45-04-XHEAD | Elevation / Tampering | headId → channel resolution | mitigate | RING-03: the tool resolves ONLY the caller's headId → that head's home-assistant channel (one satellite per head); it cannot target another head's device. dispatchForHead/getHaAdapter key on the caller's headId |
| T-45-04-NOOP | DoS (error path) | non-HA / uninitialized callers | mitigate | RING-04: missing adapter or uninitialized singleton returns `{ ok: true, note: ... }` — never throws, so timers/alarms on Telegram/Discord run without error |
| T-45-04-TOK | Information Disclosure | tool execute path | accept | The tool itself performs no HA REST/token work — it delegates to RingRunner (token-safety enforced there in Plan 02). No token surface in tool.ts |
