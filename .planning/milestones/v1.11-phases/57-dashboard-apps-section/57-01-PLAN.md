<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app metadata → dashboard DOM | `meta.title`/`meta.icon`/`meta.desc` strings, authored by the agent and read from the filesystem, are rendered into the Apps page |
| Apps page → app shell | a tile click triggers a full-page browser GET to `/apps/<slug>/`, leaving the authenticated SPA |
| dashboard → GET /apps/ | a same-origin fetch (with session cookie) to the un-authenticated enumeration endpoint |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-57-01 | Tampering/XSS | AppsPage rendering of app-supplied `meta` strings | mitigate | Render `meta.title`/`meta.icon`/`meta.desc` as plain JSX children only — rely on React's default text escaping; forbid `dangerouslySetInnerHTML`. (Authoring agent is already trusted in-process per the milestone trust model, so this is defense-in-depth, not a privilege boundary.) |
| T-57-02 | Tampering | tile `href` built from `slug` | accept | `slug` comes from the trusted server-side `listApps()` enumeration (filesystem directory names), not user input; interpolated into a same-origin path. No injection surface beyond what the server already exposes. |
| T-57-03 | Information disclosure | `GET /apps/` is un-authenticated by Phase-55 design | accept | Endpoint returns only app slug + metadata (no app code, no secrets); ownership is global per Phase-55 D-01. Sending the session cookie via `credentials:'include'` is harmless. Out of scope to change the endpoint's auth posture this phase. |
| T-57-04 | Denial of service | a broken/throwing app in the list | accept | The page stays dumb about broken state — `listApps()` does not import app modules, so a broken app lists as a normal tile; clicking it surfaces the Phase-55 per-app error boundary at `/apps/<slug>/`. No client-side handling needed. |
| T-57-SC | Tampering | npm package installs | mitigate | This phase adds NO new dependencies — `LayoutGrid` (lucide-react), `useQuery` (@tanstack/react-query), and the `request()` wrapper are all already present. No package legitimacy gate required. |
</threat_model>
