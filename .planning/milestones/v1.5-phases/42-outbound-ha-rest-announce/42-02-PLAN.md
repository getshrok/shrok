<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Shrok adapter → Home Assistant REST API | Outbound request carries the HA bearer token; the haBaseUrl is the request target |
| operator per-channel config (haBaseUrl) → fetch() URL | haBaseUrl is operator-supplied trusted config (Zod `.url()` validated at load), NOT user input |
| Shrok process → log sink | The Authorization header / token value must never cross this boundary in plaintext |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-01 | Information Disclosure | HA bearer token in outbound-request log lines | mitigate | announceOrStartConversation() never concatenates the token into any log.* string and never logs the Authorization header or fetch options object (pinned by Block D case 4); global registration of the token is done in Plan 42-01. Grep gate asserts no `log.*(...Bearer)` / `log.*(...HA_ACCESS_TOKEN)` constructions |
| T-42-02 | Server-Side Request Forgery | fetch() target URL from haBaseUrl | accept | haBaseUrl is operator-controlled per-channel config validated by Zod `z.string().url()` at config load (Phase 40), not attacker-influenced user input; the path segment is a fixed literal (`/api/services/assist_satellite/{announce|start_conversation}`) with no user-interpolated path. No SSRF surface from untrusted input |
| T-42-03 | Denial of Service | Stuck/offline satellite hanging the activation loop | mitigate | 30s AbortController timeout (ANNOUNCE_TIMEOUT_MS) on the fetch; on timeout send() logs-and-continues without throwing or retrying (D-03/P5) so the activation loop is released. Pinned by Block D case 7 |
| T-42-04 | Spoofing / Tampering | A thrown fast-error causing message loss | mitigate | Fast errors throw so ChannelRouterImpl.send() retries once then cross-channel falls back ("⚠️ Your home-assistant channel appears to be down…") — the result reaches the user somewhere rather than being silently dropped (D-03). 30s timeout deliberately does NOT throw to avoid double-delivery |
| T-42-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs — `fetch` and `AbortController` are Node 22 built-ins (research STACK confirms zero new deps). No [ASSUMED]/[SUS] packages introduced |
</threat_model>
