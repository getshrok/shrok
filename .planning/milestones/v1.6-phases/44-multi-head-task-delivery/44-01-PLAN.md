<objective>
Establish the persistence layer for the multi-head task delivery set: a new JSON column on the agents table, the `deliverToHeadIds` fields on `AgentState`/`SpawnOptions`, and the `Schedule`/`CreateScheduleOptions`/`SchedulePatch` additions with create/update handling. This is the data-model foundation every later wave threads through.

Purpose: The delivery set must be persisted ON the agent (not re-read from the schedule) because one-time task schedule rows are deleted at fire time before the agent completes (verified: `handleScheduleTrigger`, `cron === null`). It must survive resume/restart. This mirrors how Phase 34 persisted `head_id` on the agents row.

Output: `sql/008_agents_deliver_to_head_ids.sql` (new), edits to `src/types/agent.ts`, `src/db/agents.ts`, `src/db/schedules.ts`, plus unit-test coverage in `src/db/schedules.test.ts` and `src/db/db.test.ts`. tsc GREEN after this plan.
</objective>
